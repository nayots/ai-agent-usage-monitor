## Highlights

**Cursor now shows your real limit.** If your admin raised your personal Cursor spend limit above
the team default, the card used to measure you against the default — "$103 of $100", in red, when
you actually had half your $200 left. It now reads the limit Cursor enforces for *you*, and the
billing cycle along with it.

**Claude Code on an Anthropic Console account now shows something useful.** A Console (API) login
has no subscription quota, and the card used to claim Claude Code had no sign-in at all. It now
shows **today's and this month's tokens with an estimated cost** — `≈ $38.20 · 12.4M tokens` —
totalled from Claude Code's own transcripts on this PC.

**The tray shows the 5-hour window again**, not whichever window happened to be fullest.

**Tools you don't have no longer take up space.** A fresh install on a machine with only Cursor
used to show two empty "Not installed" cards.

## What changed

### Cursor: your own spend limit

Cursor reports two different limits: the team's default per-user limit, and the one actually
enforced for you, which includes any override an admin has set. The widget was reading the first.
It now reads the second, from the same caller-scoped request that also states a proper billing
cycle, so the bar, the percentage, the amount and the reset date all agree with what Cursor
enforces. The team's roster is still never requested.

### Claude Code: Console and API-key sign-ins

The API gives an ordinary key no spend or usage figures, so for these accounts the widget now reads
the token usage Claude Code records for every reply on this PC and prices it at Anthropic's
published list prices, including prompt-cache rates, fast mode, US-only inference and web search.

- It is labelled an **estimate**, because it is one: it does not know about negotiated discounts,
  and it only sees usage from this PC. Where a model is not in the price table its tokens are still
  counted and the cost is shown as `≥`, a lower bound.
- Only usage figures are read from the transcripts. Your prompts and code are never stored, shown
  or sent anywhere, and no network request is made.
- The first read scans the month once (under a second for ~260 MB here); after that only new lines
  are read.
- Every kind of non-subscription sign-in is recognised — the keyless Console sign-in that recent
  Claude Code versions use by default, API keys, `apiKeyHelper`, and environment credentials.
  Cloud-provider setups (Bedrock, Vertex, Foundry) say so plainly instead, since their prices are
  not Anthropic's.

### Tray icon

Each provider's frame now shows its **first** window — the 5-hour window for Claude Code and Codex —
instead of its fullest. A 95% weekly window no longer hides a 5% five-hour one. The one exception is
a window at its limit: that still shows the limit-reached icon, because it blocks work however empty
the five-hour window is. The tooltip still lists every window.

### Providers that aren't installed

**Show providers that are not installed** is now off by default. A tool that is installed keeps its
card whatever state it is in.

## Notes

- **Existing installs keep their saved setting.** If you want the absent cards gone, untick
  *Show providers that are not installed* once in Settings; new installs start with it off.
- `CLAUDE_CONFIG_DIR` is now honoured when locating Claude Code's credentials.
- Estimate rows have no bar and no percentage — there is no limit to measure against — and take no
  turn in the tray rotation.
