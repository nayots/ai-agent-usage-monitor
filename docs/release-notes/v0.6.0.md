## Highlights

**The tray icon says whose number it is without you having to wait for it.** The provider's
initials now live inside the bar itself, so every frame carries a reading *and* a name at the same
time. The one-second name frame that opened each turn is gone.

**The initials invert as the bar fills past them.** They are cut out of the bar rather than sitting
on it — light where the fill has reached them, dark over the empty part — so you can read how far
the bar has got straight through the letters.

**At the limit it now says 100.** The band was showing the provider's initials there instead,
because it could only show one or the other. It can show both now.

---

## Why

v0.5.0 gave each provider a turn in the tray and opened that turn with a second of its initials
before the percentage arrived. That second was the problem: a glance that landed in it learned
nothing about usage, and a glance that landed after it learned nothing about which tool the number
belonged to. The icon was answering the two questions alternately when it needed to answer both.

## What the icon looks like now

The square is in three parts: the percentage on top, one row of clear space, and a bar across the
bottom deep enough to carry the provider's initials — `CC`, `CX`, `CR`. The bar still runs the full
width and still fills to the value in the same three usage bands the widget's own rows use.

- **0–74%** — the reading in the usual ink, the bar in the accent colour.
- **75–99%** — same, the bar in the high band.
- **At the limit** — `100` knocked out of a solid block, over a bar filled edge to edge.
- **Failing** — an exclamation in the error colour, over a dotted bar. A texture is never mistaken
  for a fill, however short a fill gets.
- **Waiting** — a short rule, over bare track. A provider that has not answered yet shows no bar,
  never a zero one.
- **Stale** — greyed throughout, and the bar lifts one pixel off the left edge so the state survives
  even when every colour resolves to a single system colour in high contrast.

Every state is still distinguishable by shape and position alone, and no state is carried by colour.

**Nothing about rotation changed.** The dwell presets, the pause while the widget or the mini strip
is on screen, the pause while the session is locked, and "when something is wrong, only the trouble
rotates" all behave exactly as they did. A turn is simply one frame now instead of two.

## Known rough edge

At 100% display scaling the limit frame's `100` is three figures squeezed into nine pixels and
knocked out of a filled block, and it reads as a pale smear rather than as a number. It is legible
from 125% scaling up. Nothing is actually lost at 100%: the block and the full-width bar are both in
the exhausted colour, which is what says *at the limit* at that size.

## Under the hood

- **One icon handle per frame instead of two.** Each frame used to be rendered twice — once showing
  the name, once showing the number — so the tray could swap between them mid-turn. A frame names
  itself now, so there is nothing to swap to.
- **The initials are set a weight heavier than the figures.** At this size a capital's stems are
  narrower than a single pixel, so no pixel of one is ever fully inked and weight is the only lever
  left on contrast; a lighter weight rendered the letters as a smudge.
- **The two states with no figure draw their marks rather than typing them.** Text here is scaled to
  a target ink height, and a dash has a fraction of a capital's ink — asked to fill the band, a
  typed dash comes back as a slab the width of the icon, indistinguishable from the bar above it.

## Install

Download `AiUsageMonitor.exe` and run it. No installer, no runtime prerequisite, no administrator
rights. If your machine blocks bare `.exe` downloads, take the `.zip` instead — it contains the
same executable.

Verify the download against `AiUsageMonitor.exe.sha256`:

```powershell
Get-FileHash AiUsageMonitor.exe -Algorithm SHA256
```

Claude Code and Cursor usage are both read through endpoints their vendors do not document, and are
labelled **Unofficial** wherever they appear. Either may stop working without notice; when one
does, its card reports an error rather than showing a stale or invented number.
