## Highlights

**The notification-area icon shows one provider at a time, and turns between them.** Each turn
opens with the provider's initials for a second, then its percentage — so a number in the tray now
says *whose* it is, which it never did before.

**The number is half again as tall, and the bars nobody could read are gone.** A single bar fills to
the value beneath it, coloured by the same three usage bands the widget's own rows use, with clear
space between the two.

**The hover text finally says something.** It names the provider currently shown and lists its
windows with their percentages and reset times. It had been the fixed string *AI Usage Monitor*
since the icon existed.

---

## Why the old icon had to change

It was designed when there were two providers. With three it ran out of room and gave up in a fixed
order — first the gaps between providers, then the height of the bars, and finally whole windows,
silently, from the bottom.

At 100% display scaling that meant six quota bars sharing eight pixels: one pixel each, edge to
edge, where two readings seven points apart looked identical. The digits above them took the other
half of the icon to show a single number that named no provider, and one error mark covered the
whole glyph — so a single failing tool cast doubt on the two that were fine.

## What the icon shows now

One provider fills the square. The band carries the reading, a single bar beneath it carries the
same information a card's bar does, and two rows of clear space separate them.

- **0–74%** — the reading in the usual ink, the bar in the accent colour.
- **75–99%** — same, the bar in the high band.
- **At the limit** — the provider's initials knocked out of a solid block, with the bar full width.
- **Failing** — the initials, over a dotted bar. A texture is never mistaken for a fill, however
  short a fill gets.
- **Waiting** — the initials, over bare track. A provider that has not answered yet shows no bar,
  never a zero one.
- **Stale** — greyed throughout, and the bar lifts one pixel off the left edge so the state survives
  even when every colour resolves to a single system colour in high contrast.

The last three carry the provider's name permanently rather than a number, because in each of them
the number would say nothing: at the limit it is always 100, on a failure there is none, and before
the first read there is none yet. They also never alternate, so an icon parked on a problem holds
perfectly still.

Every state is distinguishable by shape and position alone. No state is carried by colour.

## Rotation

- **Off, 3s, 4s, 6s or 8s** — Settings → Appearance → Tray icon rotation. The default is four
  seconds.
- **It stops when it would be noise**: while the widget or the mini strip is on screen, while the
  session is locked, and when there is only one provider to show.
- **When something is wrong, only the trouble rotates.** If any provider is at its limit or failing,
  the icon turns between just those and leaves the healthy ones out.
- **Set it to Off** and the icon holds the provider that needs you most, and stops moving entirely.
  It settles there when rotation pauses, too — so an unlocked machine shows the urgent provider
  rather than whichever turn happened to be up when the screen locked.

## Under the hood

- **Turning is a handle swap, not a redraw.** Every frame is rendered once when the data or the
  taskbar's theme changes, and the icons are reused until it changes again. Redrawing per turn would
  have been roughly twenty-one thousand icon handles a day at the default dwell.
- **Rotation runs on its own timer.** The widget's existing tick slows to five seconds while the
  window is hidden — which is exactly when the tray icon is the only thing you can see.
- The icon still resolves its colours against the **taskbar's** theme rather than the application's,
  so a light app on a dark taskbar looks right.

## Install

Download `AiUsageMonitor.exe` and run it. No installer, no runtime prerequisite, no administrator
rights. If your machine blocks bare `.exe` downloads, take the `.zip` instead — it contains the
same executable.

Verify the download against `AiUsageMonitor.exe.sha256`:

```powershell
Get-FileHash AiUsageMonitor.exe -Algorithm SHA256
```

Claude Code and Cursor usage are both read through endpoints their vendors do not document, and are
labelled **Unofficial** wherever they appear. Either may stop working without notice; when one
does, its card reports an error rather than showing a stale or invented number.
