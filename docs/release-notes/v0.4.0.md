## Highlights

**Cursor is a third provider.** Its card shows what you have spent this billing cycle against the
ceiling your seat actually enforces, beside Claude Code and Codex, on the same bar as everything
else. The mechanism is **unofficial** and labelled so wherever it appears.

**A window whose real limit is money now says so.** Under the bar, in the provider's own words —
`$11.71 of $100`. The percentage stays in the USED column, so cards remain comparable at a glance
while the amount adds the one thing a percentage cannot express: how much is left.

**Nothing about Cursor's team is read to compute your number.** The endpoints that would return
your colleagues' names and work email addresses are never called, and the app refuses to report a
figure at all rather than show a team's spend as one person's.

## Cursor

Two halves, both local-first: the sign-in Cursor already stored on this machine is read from its
own state database, and Cursor's own dashboard API is asked what this seat has spent. No browser,
no cookies, no scraping.

- **The database is opened read-only** — `%APPDATA%\Cursor\User\globalStorage\state.vscdb`, the
  same file VS Code-derived editors keep local state in. Exactly three values are read from it: the
  access token, your plan type, and your team id. The email address and profile stored alongside
  them are deliberately left alone, and the team id is a request parameter and nothing else — it is
  not shown, logged, or included in a diagnostic dump.
- **Team-roster endpoints are never called.** Cursor's usage-event feed is already scoped to the
  caller, so the spend can be totalled without asking who else is on the account. Where a page ever
  carries more than one owner, the card reports no figure rather than presenting a team's spend as
  yours.
- **The token is never refreshed, rotated or rewritten.** Cursor's sign-in lasts 60 days and its
  lifecycle stays Cursor's job. The expiry is decoded locally to skip a request that could only
  fail; an unreadable expiry always falls through and sends the request as normal, so a fault in
  that check can never disable a working card.
- **The billing cycle is derived only when it can be derived honestly.** Where the provider states
  the period, that is used; where it reports a placeholder start, the cycle is worked out from a
  month-boundary end and the card records which of the two happened. The elapsed marker and the
  pace projection appear only when the period is known.
- **Not installed costs nothing.** Cursor is located from its own install locations and PATH, and
  its version is read from the executable's file metadata without starting a process.

**On the individual and Pro plans this is unverified.** Both seats available while it was built
were enterprise. The individual path is implemented from the documented shapes, and where it cannot
read a figure it degrades to an explicit *Unsupported* rather than to a wrong number.

## Spend in the provider's own units

- Cursor's monthly spend and Codex's spend limit now print their amount beneath the bar. Codex's
  `individualLimit` has always reported currency; it was previously rendered only as a derived
  percentage. It is populated on business and enterprise seats and absent on `plus`.
- **No currency symbol is ever invented.** The line is composed by the provider adapter, never
  formatted from a bare number by the UI, because only the adapter knows whether the payload named
  a unit at all. Cursor's enterprise ceiling arrives in a field that names dollars outright; its
  individual figures name nothing, and so are shown without a symbol.
- Windows whose native unit is already a percentage — every rolling quota window — are unchanged.

## Fixes

- **A malformed usage page can no longer read as `$0.00`.** Three routes to a confident zero — a
  response with no events array, an empty object, and a page promising events it did not deliver —
  now refuse rather than report. A genuinely empty billing cycle still shows zero, because there
  that is a real reading.
- **A cached spend total is now keyed on the sign-in's expiry rather than on a hash of the token.**
  A hash is still derived from a credential and still a stable per-user identifier; neither belongs
  in a record whose generated `ToString` prints every field it holds.

## Install

Download `AiUsageMonitor.exe` and run it. No installer, no runtime prerequisite, no administrator
rights. If your machine blocks bare `.exe` downloads, take the `.zip` instead — it contains the
same executable.

Verify the download against `AiUsageMonitor.exe.sha256`:

```powershell
Get-FileHash AiUsageMonitor.exe -Algorithm SHA256
```

Claude Code and Cursor usage are both read through endpoints their vendors do not document, and are
labelled **Unofficial** wherever they appear. Either may stop working without notice; when one
does, its card reports an error rather than showing a stale or invented number.
